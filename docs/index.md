## Важное пояснение:

Первая версия сайта была закончена 1 октября 2026 вместе с ЛР1.
До этого сайт содержал 5 главных вкладок для каждого из заданий
первой лабораторной работы + главня, введение и заключение. То есть
первая версия сайта с отчетами была написана конкретно для первой ЛР.
Позже я выяснил, что требуется сделать 1 сайт для всех 3 лабораторных работ.
Поэтому 27 октября сайт полностью переработан. Сейчас он содержит эту вкладку
с основной информацией по отчетам и организационным вопросам, 3 вкладки для 
лабораторных, которые заполняются параллельно с выполнением новых работ т
вкладка с заключениями - общая для всех 3. Каждая вкладка с лабораторными
удобно разбита заголовками разного уровня для удобства чтения. Также удалена
вклдка "введние", так как она оказалась излишней. На мой взгляд, сейчас
эта версия достаточно удобна для наисания всех отчетов. 
Если что-то необходимо переработать - всегда рад заняться.
