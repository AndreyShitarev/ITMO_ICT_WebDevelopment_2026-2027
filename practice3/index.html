    Практическое задание 3

    Раздача HTML страницы по HTTP

    Требования:

    • Обязательно использовать библиотеку socket

    Задание:

    Реализовать серверную часть приложения. Клиент подключается к серверу и в ответ 
получает HTTP-сообщение, содержащее HTML-страницу, которую сервер подгружает из 
файла index.html.

    Подготовка:

    Перед написанием кода сервера я создал файл index.html в той же директории, где будет сервер. Код для html файла я попросил написать нейросеть, чтобы результат был интереснее, чем просто текст. Таким образом у меня получилась следующая html-страница:

    Написание кода серверной части:

    Начало стандартное, за исключением того, что теперь метод sock.listen() имеет в качестве параметра 5. Так как теперь в качестве клиента выступает реальный браузер, а не рукописный клиент, я не могу гарантировать, что от клиента будет приходить лишь 1 подключение одновременно. Поэтому начала кода теперь выглядит так:

    import socket

sock = socket.socket(socket.AF_INET, socket.SOCK_STREAM)
sock.bind(('', 9095))
sock.listen(5) 
print("Сервер поднят и готов принять запрос")

    Далее сразу запускаем цикл while True:. В отличие от предыдущих версий сервера, в этой прием пожключения через socket.accept и получение данных через sock.recv происходят внутри цикла. Это сделано, чтобы сервер не закачивал работать сразу после того как 1 подключение завершилось, по той же причине, теперь клиент - реальный браузер.

    Код:

    while True:
    client_sock, client_address = sock.accept() # теперь сервер будет обслуживать ни 1 клиента на протяжении всей своей работы, а всех желающих
    request = client_sock.recv(1024)
    if not request:
        client_sock.close() # если браузер открыл подключение и ничего не прислал теперь просто ждем следующего подключения, а не закрываем сокет сервера
        continue

    print(f"Сервер получил запрос от {client_address}:\n{request.decode('utf-8')[:100]}... \n") # первые 100 символов запроса

    Теперь содержательная часть работы сервера. Если подключение успешно состоялось и запрос получен, пытаемся прочитать содержимое файла index.html. В любом случае пытаемся достать тело этого файла, если же сам файл не найден, то вместо тела в соответствующую переменную пишем текст ошибки тоже в html-формате.

    Код:

    try:
    with open('index.html', 'r', encoding='utf-8') as file:
        body = file.read()
except FileNotFoundError:
    body = "<h1>Файл index.html не найден<h1>" # оборачиваем текст ошибки в тело HTTP ответа

    Сейчас у нас есть тело для HTTP-ответа от сервера, но для передачи его недостаточно, нужны еще и заголовки. Поэтому сначала считаем длину тела ответа в байтах, так как эту информацию надо будет передать в заголовке. И пишем заголовки в стандартной форме:

    content_length = len(body.encode('utf-8'))

response_headers = (
    "HTTP/1.1 200 OK\r\n"
    "Content-Type: text/html; charset=utf-8\r\n"
    f"Content-Length: {content_length}\r\n"
    "Connection: close\r\n"
    "\r\n"
    )

    В первой строке заголовка пишется тип передачи, в нашем случае по HTTP протоколу.

    Во второй строке пишем какое содержимое мы передаем клиенту. В нашем случае текст в формате html и набором символов в utf-8.

    В третьей строке указывается длина передаваемого тела запроса, которую мы считали ранее.

    В 4 строке указываем, что делать с соединением после передачи запроса. Мы хотим, чтобы подключение закрылось.

    И в 5 строке обязательно ставится перенос строки, так как это требования формата заголовков.

    Остается соединить заголовки с телом ответа. И отправить HTTP-ответ клиенту.

    Код:

        response = response_headers + body
    client_sock.sendall(response.encode('utf-8'))

    client_sock.close()

    Тут для удобства проверки приведу весь код сервера:

    import socket

sock = socket.socket(socket.AF_INET, socket.SOCK_STREAM)
sock.bind(('', 9095))
sock.listen(5) 

print("Сервер поднят и готов принять запрос")

while True:
    client_sock, client_address = sock.accept() # теперь сервер будет обслуживать ни 1 клиента на протяжении всей своей работы, а всех желающих
    request = client_sock.recv(1024)
    if not request:
        client_sock.close() # если браузер открыл подключение и ничего не прислал теперь просто ждем следующего подключения, а не закрываем сокет сервера
        continue

    print(f"Сервер получил запрос от {client_address}:\n{request.decode('utf-8')[:100]}... \n") # первые 100 символов запроса


    try:
        with open('index.html', 'r', encoding='utf-8') as file:
            body = file.read()
    except FileNotFoundError:
        body = "<h1>Файл index.html не найден<h1>" # оборачиваем текст ошибки в тело HTTP ответа

    content_length = len(body.encode('utf-8'))

    response_headers = (
        "HTTP/1.1 200 OK\r\n"
        "Content-Type: text/html; charset=utf-8\r\n"
        f"Content-Length: {content_length}\r\n"
        "Connection: close\r\n"
        "\r\n"
        )


    response = response_headers + body
    client_sock.sendall(response.encode('utf-8'))

    client_sock.close()
